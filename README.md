# Missingness-shortcut model-selection audit: code-only release

This repository contains only the computational source code used to audit when historical validation selects the wrong model after an outcome-associated missingness shortcut changes. It does not contain datasets, derived results, figures, manuscripts, model checkpoints, credentials, or author information.

## Repository contents

- `code/`: controlled tabular benchmark, negative controls, dose experiments, statistics, and equal-budget adversarial ablation.
- `energy_case/`: CityLearn preparation, urban peak-warning experiment, and analysis.
- `figures/`: code and Matplotlib style for regenerating the five composite figures after the experiments finish.
- `environment/`: frozen Python requirements for the general benchmark and CityLearn case.
- `verify_upload.py`: code-only and privacy-oriented release check.

Generated files are written under `artifacts/` or `figures/` and are excluded by `.gitignore`.

## Environment setup

The TabPFN dependency may download model weights separately. Those weights are not part of this repository and remain subject to the [Prior Labs license](https://github.com/PriorLabs/TabPFN).

General benchmark:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r environment\requirements-general.txt
```

CityLearn case:

```powershell
python -m venv .venv-energy
.\.venv-energy\Scripts\python.exe -m pip install -r environment\requirements-energy.txt
```

## General benchmark

Run commands from the repository root. A one-dataset, one-seed check is:

```powershell
.\.venv\Scripts\python.exe code\stage6_adversarial_ablation.py --mode smoke --device cpu --threads 4
```

The frozen full design uses 12 datasets, 10 seeds, seven validation associations, seven target associations, and a fixed four-model candidate pool:

```powershell
.\.venv\Scripts\python.exe code\stage6_adversarial_ablation.py --mode full --device cpu --threads 4
```

Earlier scripts retain the exploratory boundary, independent holdout, proxy and latent negative controls, repeated-channel dose, stress-selection, unified-matrix, and frozen-statistics analyses. They are kept as separate stages so the confirmatory route is distinguishable from exploration.

## CityLearn urban peak-warning case

Clone the exact public release into the path expected by the code:

```powershell
git clone --branch v2.5.0 --depth 1 https://github.com/citylearn-project/CityLearn.git data/citylearn_v2.5.0
git -C data/citylearn_v2.5.0 rev-parse HEAD
```

The study used commit `29062af6d077409e1c37a3e53a6cac30fd4d02bc`. Then run:

```powershell
.\.venv-energy\Scripts\python.exe energy_case\prepare_citylearn.py
.\.venv-energy\Scripts\python.exe energy_case\run_gate.py --full17
.\.venv-energy\Scripts\python.exe energy_case\analyze_full17.py
```

CityLearn provides the public temporal traces. The outcome-conditioned missingness change is generated by this repository as a controlled stress test; it is not claimed to be a naturally observed gateway failure.

## Figure regeneration

After the expected result tables have been generated under `artifacts/`:

```powershell
.\.venv\Scripts\python.exe figures\make_five_panel_figures.py
```

The figure files remain ignored because this is a code-only upload package.

## Pre-upload verification

Run:

```powershell
python verify_upload.py
```

The check rejects data, results, model files, archives, documents, rendered figures, local user paths, common credential patterns, email addresses, and Python syntax errors.

## Scope and license

The empirical target oracle is the lowest-loss member of a fixed four-model pool on each finite labeled target sample. It is retrospective and not deployable. The `0.02` regret boundary is a preregistered screening threshold, not an externally validated utility threshold.
